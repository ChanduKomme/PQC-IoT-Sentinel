# Results and generated tables

[primary_24h.csv](primary_24h.csv) and [network_resilience.csv](network_resilience.csv) retain compact Version 1 headline tables. [reproduced_summary.json](reproduced_summary.json) contains the more detailed raw-data reconstruction, quantile method, packet counts, retry outcomes and stage failures.

Small generated tables are in [derived/](derived/). The full per-message RTT and delivery-gap tables are generated by `analysis/reproduce.py` into `.reproduce/results/` to avoid redundant copies of the raw evidence.

The 1,000-outcome network windows are structured terminal samples. Completed-cycle denominators add raw metadata-fetch failures omitted from those samples. The original archived summaries and seals are not rewritten. Read the [measurement notes](../docs/MEASUREMENT_NOTES.md) before combining metrics.
