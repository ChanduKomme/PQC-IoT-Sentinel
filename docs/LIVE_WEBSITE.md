# Live research website

The public evidence portal for PQC-IoT Sentinel is:

**https://pqcsecrity.live/evidence**

## Role of the website

The website is a dissemination and inspection layer for the project. It can present project context, selected evidence, dashboards, screenshots, and result summaries.

It is **not** the authoritative denominator for the conference paper's quantitative claims. Publication statistics come from the archived experiment records and analysis/reconstruction described in the manuscript.

## Why this distinction matters

Operational dashboards can include:

- data outside the exact paper analysis windows;
- invalid or diagnostic runs retained for provenance;
- additional raw events beyond the selected research sample;
- telemetry counters with semantics different from completed application cycles.

For that reason, paper claims should be cross-checked against `results/`, the artifact notes, and the archived evidence rather than copied from live aggregate counters.

## Citation/use

The website can be cited as a public project evidence portal, but exact reproducibility of the paper requires the underlying archived records and analysis artifacts.
