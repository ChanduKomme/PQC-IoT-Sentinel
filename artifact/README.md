# Conference Version 1 artifact index

This directory contains the documentation needed to interpret the Version 1 conference evidence correctly.

- [`ARTIFACT_SCOPE.md`](ARTIFACT_SCOPE.md) — claim boundaries and non-claims.
- [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md) — integrity checks and reproduction levels.
- [`REVIEWER_GUIDE.md`](REVIEWER_GUIDE.md) — quick path for reviewers.
- [`EXPERIMENT_INDEX.md`](EXPERIMENT_INDEX.md) — official run IDs, manifest hashes, exclusions, denominator correction, and retry semantics.
- [`FIRMWARE_PROVENANCE.md`](FIRMWARE_PROVENANCE.md) — known binary identities and source/build provenance limits.
- [`SHA256SUMS.txt`](SHA256SUMS.txt) — identities of the prepared paper PDF and sanitized source archive.

Publication statistics should be interpreted together with the denominator/timing notes in `docs/MEASUREMENT_NOTES.md`.
